# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| Earlier than 2.0.0 | No |

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository if it is available. Otherwise, open an issue asking for a private contact channel, and do not include vulnerability details in it.

Please include the affected version, the impact, and the steps needed to reproduce the issue. This is a personal project maintained on a best-effort basis, so no response time is guaranteed.

## Security model

The application has no accounts, sessions, cookies, forms, stored data, or secrets. See [docs/SECURITY_AUDIT.md](docs/SECURITY_AUDIT.md) for the latest review.
